# Blog Website  

A simple blog website built using Flask, allowing users to create, read, and interact with blog posts.  

## Features  
- User authentication (login/register)  
- Create, edit, and delete blog posts  
- admin interface with more prilages
- Responsive UI
- Write and read comment for the post
